Como Fazer
Não há repositório base. Você parte de um notebook vazio e segue o caminho do Expert, com o seu tema:

1. Defina o objetivo: Lei da atração
2. Separe as fontes:
https://www.youtube.com/watch?v=oxmp2w5rRq0&pp=ygUXbGVpIGRhIGF0cmHDp8OjbyByZXN1bW8%3D

https://www.youtube.com/watch?v=ckkOmwW_Bas
https://www.youtube.com/watch?v=w5Tj19xCNXY
4. Crie o notebook: 
https://stealthelook.com.br/lei-da-atracao-o-que-e-como-funciona-e-como-usar-a-seu-favor/
https://revista.meuretiro.com.br/dicas/ativar-a-lei-da-atracao/
https://pt.wikipedia.org/wiki/Lei_da_atra%C3%A7%C3%A3o
5. Converse com as fontes. Faça perguntas no chat e clique nas citações para ver de onde veio cada resposta;
6. Gere os materiais. No Estúdio, peça mapa mental, slides, guia de estudos ou resumo em áudio, e baixe o que puder.
